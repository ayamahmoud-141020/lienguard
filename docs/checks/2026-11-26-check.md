## ACs with no valid test
- AC-12.4 (concurrency clause): defect. `src/server/batches.ts` `extractDocument` calls `getExtractor()` on every extract request. That calls `GeminiExtractor.fromApiKey(...)`, which calls `geminiGenerate(apiKey, maxConcurrency)` in `src/ai/gemini.ts`, which builds a new `limitConcurrency` limiter every time. So the limit applies per request, not per server instance. The processing page runs 4 extract requests at once, so up to 4 Gemini calls can run at once even though the default is 2. `getWriter()` in `src/server/drafts.ts` builds its own separate limiter too. The test only checks the helper on its own.
